## Requisitos

Para utilizar a homepage, é necessário ter o **Docker** e o **Docker Compose** instalados.

## Execução

No diretório do Beluga Talks, execute o seguinte comando:

```bash
docker compose -f docker/beluga-compose.yml up
```

Aguarde até a homepage terminar de carregar. Quando terminar, a homepage estará disponível em `localhost:8888`.
