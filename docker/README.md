## Requisitos

Para utilizar o app, é necessário ter o **Docker** e o **Docker Compose** instalados.

## Execução

No diretório do Beluga Talks, execute o seguinte comando:

```bash
docker compose -f docker/beluga-compose.yml up
```

Aguarde até o app terminar de carregar. Quando terminar, o app estará disponível em `localhost:8888`.
